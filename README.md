# Ranbeer Kamlapure — Portfolio

Personal portfolio for **Ranbeer Kamlapure** (Full-Stack Developer). Theme: **CHROME / CONSCIOUSNESS**.

Single-page Vite + React + Tailwind site with GSAP ScrollTrigger storytelling, Framer Motion UI motion, Lenis smooth scroll, a lazy-loaded Three.js chrome accent, Anime.js headline reveal, SEO meta + JSON-LD Person, and `public/llms.txt`.

## Run locally

```bash
npm install
npm run dev
```

Dev server: **http://127.0.0.1:4327**

```bash
npm run build    # production build → dist/
npm run preview  # preview build on port 4328
```

## Stack

- Vite · React · JavaScript · Tailwind CSS v4
- GSAP + ScrollTrigger · Framer Motion · Lenis
- Three.js (+ React Three Fiber) · Anime.js · Lucide React
